# Aldora Mengaji Enterprise

Premium Islamic learning web application built with HTML, CSS, and JavaScript.

## Features
- Hijaiyah Learning
- Iqro 1–6
- Tajwid Guide
- Prayer Guidance
- Audio Learning System
- Quran Learning Modules
- Dark / Light Mode
- Progress Tracking
- Responsive UI
- Offline PWA Support

## Technology
- HTML5
- CSS3
- JavaScript
- Web Audio API
- Speech Synthesis API
- Local Storage
